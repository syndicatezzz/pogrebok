# Погребок — сайт кафе

Сайт кафе «Погребок» (Новосибирск, Петропавловская ул., 1).

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Главная страница |
| `menu.html` | Меню (все блюда и цены) |
| `staff.html` | Персонал |
| `contacts.html` | Контакты, карта, бронь |
| `css/style.css` | Оформление (цвета, шрифты, отступы) |
| `js/main.js` | Анимации, вкладки меню, карта |
| `assets/` | Картинки и библиотека карты |

## Как поменять цену или блюдо

1. Откройте `menu.html` на GitHub и нажмите на значок карандаша (Edit).
2. Найдите блюдо через Ctrl+F. Строка выглядит так:
   `<h4>Борщ</h4><span class="dots"></span><span class="price">100 ₽</span>`
3. Поменяйте текст или цену, нажмите **Commit changes**.
4. Через 1–2 минуты изменения появятся на сайте.
